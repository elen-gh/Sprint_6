# Sprint_6
# Page Object. Проект UI-автотесты для учебного сервиса «Яндекс.Самокат»
выполнен на Python с использованием библиотеки Pytest и фреймворка Selenium

## Структура проекта:
* `allure-results/` — тестовые модули
* `locators/` — локаторы
* `pages/` — страницы и экраны
* `tests/` — тестовые модули
* `src/` — тестовые данные, конфигурация
* `conftest.py` — фикстуры (настройка драйвера)
* `.gitignore` — список игнорируемых файлов
* `README.md` — описание проекта

## Написаны тесты на функциональность:
* «Выпадающий список в разделе «Вопросы о важном»» - модуль test_faq_list.py:
    * отдельный тест на каждый вопрос
* «Заказ самоката - флоу позитивного сценария» - модуль test_order_positive.py:
    * два набора данных (набор 1 - обязательные поля, набор 2 - все поля);
    * две точки входа в сценарий: кнопка «Заказать» вверху и внизу страницы;
    проверки:
    * всплывающее окно с сообщением об успешном создании заказа;
    * клик на логотип «Самоката» - редирект на главную страницу «Самоката»;
    * клик на логотип Яндекса - редирект на главную страницу Дзена
